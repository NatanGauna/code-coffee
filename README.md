# Code & Coffee ☕

Um projeto web para um café com foco em programadores. Site responsivo com cardápio, informações de contato e sobre.

## 📁 Estrutura do Projeto

```
code-coffee/
├── index.html        # Página inicial
├── cardapio.html     # Cardápio de bebidas e alimentos
├── contato.html      # Formulário de contato
├── sobre.html        # Informações sobre o café
├── style.css         # Estilos do projeto
└── images/           # Pasta com imagens
```

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/NatanGauna/code-coffee.git
```

2. Abra o arquivo `index.html` no seu navegador

Não há dependências externas - o projeto é totalmente estático!

## 📄 Páginas

- **Home** (`index.html`) - Página principal do site
- **Cardápio** (`cardapio.html`) - Bebidas e alimentos disponíveis
- **Sobre** (`sobre.html`) - Histórico e informações do café
- **Contato** (`contato.html`) - Formulário para entrar em contato
